## Rule

This directory exists to preserve the **original historical pieces as original historical pieces**.

Do not:
- modernize the wording;
- clean up profanity;
- convert vernacular into academic language;
- rewrite the original AI responses;
- merge later doctrine back into earlier records;
- silently correct an old interpretation;
- replace an original source with a later summary.

The exact source is the source.

## Preservation method

The first recovered source family is pinned in `ORIGINAL_SOURCE_MANIFEST.csv`.

Each record names:
- the canonical source repository;
- the exact source commit;
- the exact historical path;
- the independent SHA-256 already present in the canonical source-coverage rail when available;
- an explicit `DO_NOT_REWRITE_OR_NORMALIZE` rule.

A commit-pinned path plus its digest is the frozen original. Later thesis, academic, engineering, or public-facing writing must cite and interpret that source **without changing what the source was**.

This approach intentionally avoids creating a "cleaned up" historical copy that could later be mistaken for the original.
