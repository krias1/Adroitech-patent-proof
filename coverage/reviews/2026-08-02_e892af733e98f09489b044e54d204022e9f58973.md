## What this commit establishes

This commit creates an explicit repository-backed session-close and resume protocol whose stated purpose is to make the repository a durable handoff point across ChatGPT threads, devices, sessions, and future authorized agents. It explicitly states that the operator should not have to reconstruct prior sessions from memory or repeat work already discussed, verified, or completed.

The protocol converts continuity from conversational convenience into an operational procedure. On an operator close/save trigger it requires review of material work, separation of verified live state from operator-stated facts, plans, unresolved questions, failures/rollbacks and exact next actions; reading current controls before writing; updating the rolling checkpoint and affected functional records; creating a substantial-work handoff/receipt; protecting live authentication secrets; verifying repository writes; returning the real final commit SHA; and leaving a ranked next action.

For new sessions it requires a deterministic bootstrap through `START_HERE.md`, `CURRENT_RESUME_POINT.md`, `RESUME_POINT.md`, and the relevant detailed record. It expressly forbids forcing the operator to repeat information already preserved in the repository or authorized rails.

For live infrastructure it separates brainstorming/planning from authorization, requires inspection before change, backup before editing, bounded changes, configuration testing, known-good rollback, user-visible verification, and forbids claiming success without output or operator confirmation.
