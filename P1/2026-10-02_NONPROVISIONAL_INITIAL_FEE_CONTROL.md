# Nonprovisional Initial Fee Control — 2026-10-02

## Scope

This control records the current USPTO initial utility-application fee baseline for the operative Adroitech OS nonprovisional filing package. It does **not** assert small- or micro-entity entitlement; entity status must be affirmatively verified before paying a reduced rate.

## Operative claim count

Current canonical candidate set: **20 total claims / 3 independent claims**.

At that count, the current USPTO excess-claim thresholds (>20 total or >3 independent) are not crossed. Therefore the baseline below includes **no excess-claim fee**, provided the final filed claim set remains at 20 total / 3 independent and contains no multiple-dependent-claim fee trigger.

## Current official USPTO fee baseline

Source checked 2026-10-02: USPTO Fee Schedule, last revised 2026-08-14, effective schedule stated as 2025-01-19 with later revisions.

For an electronically filed original nonprovisional utility application:

| Fee | Regular | Small entity | Micro entity |
|---|---:|---:|---:|
| Basic utility filing | $350 | **$70 electronic small-entity rate** | $70 |
| Utility search | $770 | $308 | $154 |
| Utility examination | $880 | $352 | $176 |
| **Baseline initial total** | **$2,000** | **$730** | **$400** |

Notes:

1. The $70 small-entity basic filing figure is the USPTO's special electronic-filing rate (fee code 4011). The ordinary small-entity basic filing fee shown in the schedule is $140; use the electronic rate only when the filing qualifies for it.
2. Micro status requires a proper certification under 37 CFR 1.29 before relying on micro rates. Do not infer eligibility from company size or income without the required inquiry/certification.
3. Small status likewise requires a reasonable eligibility inquiry before assertion/payment at reduced rates.
4. Filing through Patent Center avoids the non-electronic filing surcharge.
5. File specification, claims, and abstract in compliant DOCX to avoid the non-DOCX surcharge unless a deliberate, documented exception is required.
6. If the specification + drawing page count crosses the current electronic application-size threshold, add the applicable size fee after final rendered-page QA.
7. Recalculate immediately before certification/payment because USPTO fees can change.

## Filing-completeness rule

Pay the basic filing, search, and examination fees at filing. File the inventor oath/declaration with the initial package rather than intentionally generating a late surcharge. Current USPTO filing guidance warns that filing/search/examination fees or the oath/declaration submitted after the application filing date can trigger a late surcharge.

## Remaining fee gate

**BLOCKER BEFORE FINAL PAYMENT:** establish the filing entity status (regular / small / micro) from current facts and preserve the basis for the assertion/certification. Until that is done, the zero-reconstruction packet should carry all three current totals rather than silently choosing the cheapest rate.
