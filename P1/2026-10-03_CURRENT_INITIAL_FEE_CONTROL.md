## Current baseline for the operative 20-claim / 3-independent-claim set
The present claim count does not itself trigger excess-total-claim or excess-independent-claim fees. Those thresholds begin above 20 total claims or above 3 independent claims. Recalculate if the filing set changes.

For an electronic Patent Center utility filing, the current basic filing/search/examination amounts are:

- Regular entity: $350 basic filing + $770 search + $880 examination = **$2,000**.
- Small entity using the USPTO's electronic-filing small-entity basic filing fee: $70 basic filing + $308 search + $352 examination = **$730**.
- Micro entity: $70 basic filing + $154 search + $176 examination = **$400**.

Do not select a discounted status merely because it is cheaper. Small-entity entitlement must be established before asserting it. Micro-entity status requires the applicable certification and qualification.

## Avoidable initial surcharges
File electronically through Patent Center and file the specification, claims, and abstract in DOCX unless a documented filing constraint justifies otherwise. The USPTO filing guide confirms that filing/search/examination fees paid after filing incur a late surcharge, and a late oath/declaration also incurs a surcharge. This sprint therefore treats same-session payment and oath/declaration as filing requirements rather than intentional missing-parts items.

Application-size fees must be recalculated after the final rendered filing package is frozen. The USPTO guide states that an electronically filed application incurs an application-size fee when the specification-and-drawing page count exceeds 133 pages. Multiple-dependent-claim fees, if any, must likewise be checked against the final claims.

## Filing gate
**NOT YET A FINAL PAYMENT QUOTE.** Final payment amount requires: (1) verified entity status; (2) frozen claim count and multiple-dependent-claim check; (3) final application-size calculation; (4) confirmation that DOCX/non-electronic surcharges are avoided; and (5) a fresh fee-schedule check immediately before submission.

This control exists to prevent deliberate fee deferral and to give the zero-reconstruction packet a current authoritative baseline.
